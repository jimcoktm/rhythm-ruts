# Rhythm Ruts

A side-scrolling dirt bike game. No turning. Hold the gas, lean the bike in the air, and stick the landing.

## Play it on your computer

You need [Node.js](https://nodejs.org) (the LTS version). Then:

1. On this GitHub page, click the green **Code** button, then **Download ZIP**. Unzip it.
2. Open a terminal in that folder. On a Mac, right-click the folder and choose New Terminal at Folder. On Windows, type `cmd` in the folder's address bar.
3. Run these two commands, one at a time:

```bash
npm install
npm run dev
```

4. Open the address it prints, usually http://localhost:8080

## How to ride

- **D** or the right arrow is gas. **A** or the left arrow is brake.
- **W** leans back (nose up). **S** leans forward (nose down).
- On a phone, turn it sideways. Gas and brake are on the left. Lean back and forward are on the right.

Best times are saved in the browser on that device.
